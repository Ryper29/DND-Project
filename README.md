# Dungeons & Dragons Console Prototype

A C# console prototype for a D&D-inspired fantasy RPG. This is not currently a Unity project or a finished game.

## Status

The project contains basic character creation and a simple turn-based combat prototype. Gameplay and rules are still under development.

## Current Features

- Character creation: enter a name and choose a race and class.
- Six ability scores generated by rolling 4d6 and dropping the lowest die.
- Basic race and class definitions.
- Equipment catalog with basic weapon and armor equipping.
- Turn-based combat flow: player-controlled party turns and enemy attacks.
- Dice rolling, combat events, hit points, experience, and levels.
- Console presentation and automated unit tests.

## Known Limitations

- Defend and item-use actions are not implemented.
- Spell choices and effects are limited; target selection is not available.
- Race does not yet affect ability scores or other mechanics.
- Rogue and Cleric do not yet have class-specific abilities.
- Inventory is limited to equipped weapons and armor; consumables and item management are missing.
- Exploration, quests, narrative campaign, and save/load are not implemented.
- The console interface is a prototype; the game has no 2D/3D graphics or Unity integration.
- Automated tests do not cover the full interactive game flow.

## Technology

- C#
- .NET 8
- Console application
- xUnit tests

## Run

Install the .NET 8 SDK, then run from the repository root:

```sh
dotnet run
```

The test project can be checked with:

```sh
dotnet test DnD.Tests/DnD.Tests.csproj
```
